# Changelog

## 1.6.2

- Publish the app as a Home Assistant repository with installation, backup, and migration instructions.
- Start new collections empty; preserve existing databases and restored collections.
- Remove personal starter entries and the private collage download link.
- Add source synchronization and private-data checks for development.

## 1.6.1

- Add the Require login setting; it is enabled by default.
- Allow passwords of 8 characters or more when login is enabled.
- Preserve saved login settings and collection data when toggling login.

## 1.6.0

- Package Shoes for Home Assistant OS with persistent database and photo storage.
- Support storage locations, shoe and box photos, backups, and Stored / Taken out status.
