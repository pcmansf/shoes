# Shoes Collection

Keep a household shoe collection on your Home Assistant device. Add shoe and box photos, organize storage locations, and track which pairs are stored or taken out. Open it from a phone or computer on your home network.

- Starts with an empty collection; restore your own backup or add pairs.
- Saves the database and photos persistently in the app's `/data/shoes` directory.
- Offers optional login, enabled by default, with an 8-character minimum password.
- Runs on 64-bit Raspberry Pi (`aarch64`) and Intel/AMD (`amd64`) Home Assistant OS devices.
- Needs no access to Home Assistant configuration, host devices, or the Supervisor API.

Read the **Documentation** tab before configuring or migrating an existing local installation. Version 1.6.2.
