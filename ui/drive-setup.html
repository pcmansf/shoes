ONE-TIME CONNECTION

Connect your Google Drive.

This connects your own Google account to the private file picker. Selected photos are copied into your collection. The app does not edit or change sharing on your Drive files.

  1. In Google Cloud Console, create or select a project. Enable Google Drive API and Google Picker API.
  2. Configure Google Auth Platform branding and audience. For personal testing, keep the app in Testing and add your Google email as a test user. Add the scope https://www.googleapis.com/auth/drive.file.
  3. Create an OAuth client with type Web application. For Windows, add http://localhost, http://localhost:5173, http://127.0.0.1 and http://127.0.0.1:5173 to Authorized JavaScript origins.
  4. Create an API key in the same project. Restrict it to Google Picker API and Google Drive API. For website restrictions, allow http://localhost:5173/*, http://127.0.0.1:5173/*, your eventual HTTPS app address, and https://docs.google.com/*.
  5. Copy the Web OAuth client ID, the API key, and the project's numeric project number into the configuration template. A client secret is not needed.

Download configuration template

Save the configuration

Windows: save the edited file as data/google-drive.json inside the Shoes folder.

Raspberry Pi: save it as /var/lib/shoes/google-drive.json. Make it readable by the app:

sudo chown shoes:shoes /var/lib/shoes/google-drive.json
sudo chmod 600 /var/lib/shoes/google-drive.json

Close and reopen the Drive picker after saving. The app reads this file each time you open the picker.

Pi network access

Google sign-in needs an approved HTTPS origin for normal network access. The default http://raspberrypi.local:3000 address cannot use it. Set up HTTPS under a domain you control, register that exact origin with Google, add it to SHOES_ORIGINS, and preserve the Host header through your proxy.

For testing without HTTPS, use an SSH tunnel to the Pi and open the app as localhost. See GOOGLE_DRIVE_SETUP.md in the ZIP for commands.

The browser-visible API key identifies your app; keep its website and API restrictions in place. OAuth tokens stay in the picker window's memory and are not saved in this configuration or sent to the shoe server. The Google scope permits access to files selected through this app; this implementation only downloads them.
